# Furever Family — Pet Health Care App

UX case study by **Govind Patel**: an all-in-one app for pet parents to book vets, track care, ask verified experts, and book an ambulance in an emergency.

**Live site:** https://govind28patel-bit.github.io/pet-health-care-app/

- Research: survey, 8 interviews (pet parents, vets, stores, hostels), stakeholder map, competitor audit, affinity mapping
- Design: personas, empathy maps, information architecture, mid-fi to final UI, SOS emergency flow, storyboard
- Tools: Figma
